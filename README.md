# Multimodal RAG Assignment Project

This repository implements a **Retrieval-Augmented Generation (RAG)** chatbot over 5 required research papers, with:

- PDF ingestion + chunking
- FAISS vector database for semantic retrieval
- Open-source LLM integration via Ollama
- Conversational memory (last 4 interactions)
- Automated 10-question evaluation
- Final report generation as PDF

---

## 1) Assignment Coverage Status

### Completed

1. **PDF ingestion**
   - Reads all 5 papers from `data/papers/`
   - Extracts text + table-like content
   - Extracts embedded images to `data/extracted_images/`

2. **Chunking and embeddings**
   - Recursive chunking in `src/ingestion.py`
   - Embeddings using `BAAI/bge-small-en-v1.5` in `src/embeddings.py`

3. **Vector DB creation**
   - FAISS text index in `vectorstore/papers.index`
   - Metadata in `vectorstore/chunks_metadata.json`
   - Image vector store support also implemented

4. **Open-source model integration**
   - Text generation: `qwen2.5:1.5b` via Ollama
   - Vision generation: `qwen3-vl:4b-instruct` via Ollama

5. **Conversation memory**
   - Last 4 interactions kept using `deque(maxlen=4)` in `src/rag_pipeline.py`

6. **10 predefined questions + evaluation**
   - Implemented in `run_predefined_evaluation.py`
   - Outputs results JSON to `report/evaluation_results.json`

7. **Final report PDF**
   - Generated by `report/generate_final_report_pdf.py`
   - Output: `report/final_report.pdf`

### Notes

- Evaluation uses a **self-devised metric** (allowed by assignment) with:
  - Keyword accuracy
  - Relevance
  - Contextual awareness
  - Response quality

## 2) Project Structure

- `src/ingestion.py` - PDF extraction and chunking
- `src/vector_store.py` - text FAISS index creation
- `src/retrieval.py` - semantic text retrieval
- `src/llm.py` - text LLM (Ollama)
- `src/image_metadata.py` - image metadata creation
- `src/image_retrieval.py` - image FAISS index + retrieval
- `src/vision.py` - vision LLM (Ollama)
- `src/rag_pipeline.py` - end-to-end RAG logic + memory
- `streamlit_app.py` - chatbot UI
- `run_predefined_evaluation.py` - 10-question evaluation runner
- `report/generate_final_report_pdf.py` - final PDF report generator

## 3) Setup Instructions 

### A) Clone the repository

```powershell
git clone <YOUR_REPO_URL>
cd <YOUR_REPO_FOLDER>
```

### B) Create and activate virtual environment

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If activation is blocked:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### C) Install dependencies

```powershell
pip install -r req.txt
```

> `req.txt` is the lean dependency file for this project flow.
> `requirements.txt` is currently a much larger environment snapshot.

### D) Install and start Ollama

1. Install Ollama from: <https://ollama.com/download>
2. Verify installation:

```powershell
ollama --version
```

If `ollama` is not recognized, use:

```powershell
& "C:\Users\<YOUR_USER>\AppData\Local\Programs\Ollama\ollama.exe" --version
```

3. Start Ollama:

```powershell
ollama serve
```

If port 11434 is already in use, Ollama is already running and you can skip `serve`.

4. Pull required models (new terminal, same machine):

```powershell
ollama pull qwen2.5:1.5b
ollama pull qwen3-vl:4b-instruct
```

5. Verify Ollama API:

```powershell
Invoke-WebRequest http://localhost:11434/api/tags -UseBasicParsing
```

## 4) How to Run (End-to-End)

### Step 1: Download assignment PDFs (if not already present)

```powershell
python download_papers.py
```

### Step 2: Ingest PDFs (text + table + images)

```powershell
python test_ingestion.py
```

### Step 3: Build text vector store (FAISS)

```powershell
python -m src.vector_store
```

### Step 4: Build image metadata (for multimodal retrieval)

```powershell
python -m src.image_metadata
```

### Step 5: Run chatbot UI

```powershell
streamlit run streamlit_app.py
```

---

## 5) Run the 10-Question Evaluation

After Ollama is running and models are pulled:

```powershell
python run_predefined_evaluation.py
```

This creates:

- `report/evaluation_results.json`

The script automatically:

- asks 10 predefined questions
- runs retrieval + answer generation
- computes per-question and aggregate evaluation scores

---

## 6) Generate Final Report PDF

After evaluation JSON is generated:

```powershell
python report\generate_final_report_pdf.py
```

Output:

- `report/final_report.pdf`

If you want to test PDF formatting before running the full evaluation, use:

```powershell
python report\generate_final_report_pdf.py --evaluation report\evaluation_results.sample.json --output report\final_report_sample.pdf
```

## 8) Troubleshooting

1. **Ollama connection error**
   - Ensure `ollama serve` is running.
   - Verify: `http://localhost:11434/api/tags` is reachable.

2. **Model not found**
   - Run:
     - `ollama pull qwen2.5:1.5b`
     - `ollama pull qwen3-vl:4b-instruct`

3. **Missing FAISS files**
   - Run `python -m src.vector_store` again.

4. **No image metadata**
   - Run `python -m src.image_metadata`.
